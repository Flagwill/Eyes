# Eyes Preview Gallery

These files are development snapshots used to check composition, eye geometry, attention, and surface light. They are not loaded by the application.

- `brows-shaped-focused.png` / `expressions-shaped-brows.png`: real-Rive previews of the wider-than-eye brows with a thick inner head, shallow arch and tapered outer tail (2026-10-26).

- `brows-focused.png` / `expressions-brows.png`: real-Rive previews of the shorter, thicker straight-cut eyebrows, anchored close to the upper lids and using the eyes' purple (2026-10-26). Brows now appear only for focus and confusion.

- `expressions-accessories.png`: paused real-Rive gallery with shared vector brows, question marks, stars, hollow glasses, alert strokes and sleepy cues (2026-10-26). All eight canvases were verified as Rive, with no fallback.

- `eyes-smooth-performance.mp4`: 16-second recording of the actual shared Rive renderer after introducing clamped C2 lids and one clock for gestures, gaze and reflection phase (2026-10-25). It shows entry and the following acting phrases at the default energy, with labels for all eight emotions.

- `expressions-performance-before.png` / `expressions-performance.png`: paused real-Rive comparison before and after the eight-emotion performance revision (2026-10-25). Inspect the live gallery's “重播表情” control for entry, partner-lid delay and settling; static screenshots cannot demonstrate motion quality.

- `expressions-rive.png`: eight expressions rendered by the real Rive runtime (2026-10-24), paused for comparison. `/gallery.html` plays their authored eyelid motions by default.

- `expressions-sentient.png`: all eight expressions after integrating the Sentient five-point rig (2026-10-24). The live, shared-engine comparison is available at `/gallery.html` in the local debug server.

- `preview.jpg`: browser debug console.
- `preview-fullscreen.jpg`: immersive full-screen composition.
- `preview-attention*.jpg`: cursor attention and left/right gaze iterations.
- `preview-balanced-cursor.jpg`: balanced pointer-following state.
- `preview-geometry-*.jpg`: eye proportions and spacing studies.
- `preview-highlights.jpg`, `preview-surface-*.jpg`: soft surface-light studies.

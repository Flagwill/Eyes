# Eyes 眼神表演约定

## 整体朝向

把双眼、眼面内的面光、眉线、问号、星星及工作道具视为同一张脸。共享引擎在眼睑形变之外输出 `frame.face`，包含 `yaw`、`pitch` 和行主序投影矩阵；相机距离固定为 850 模型单位，不随屏幕大小或像素密度变化。向右看时左侧出屏、右侧入屏；俯仰使上下边缘产生连续的近大远小。原有轻微侧倾也在同一矩阵中计算，不能在宿主重复旋转。

模型坐标与屏幕一致，`y` 向下；正 `pitch` 表示向下看，并使上缘靠近观察者。旋转基为 `y` 向上，因此矩阵对俯仰角取负号，避免上下方向的三维旋转反向。

视线弹簧先响应，整体转向弹簧再跟随，并以不足 1% 的极轻收势停住；转向速度仍不超过每 60 Hz 帧 0.04 弧度。不使用独立随机摇摆或第二个时钟。左右转动限制为 ±0.38 弧度、俯仰为 ±0.28 弧度；思考的侧上视线自然抬头，编辑/阅读低头，开心轻提，困倦微垂，惊讶略仰。所有参数在状态中断后继续收敛；重复状态不重播起势。静止光标保持朝向，暂停不积累隐藏时间；减少动态效果提高阻尼并保留静态朝向。

浏览器以 CSS `matrix3d` 合成透明眼睛画布，Rive 和 Canvas 使用同一逻辑；Plasma 用 Qt `Matrix4x4` 合成实际输出尺寸的 GPU 场景，参考 GLSL 场景也共用矩阵。眉线与道具位于整体投影内、眨眼压缩外，面光沿眼形一同转动。布局和指针映射始终读取未投影的舞台尺寸，避免画布视觉边界反过来引起缩放与视线抖动。局部道具操作与浅浮雕继续使用原有模型，不另起随机动画。设计与验证边界见 [ADR-010](decisions/010-shared-face-perspective.md)。

## 目标与参考

眼睑与视线承担情绪，面光补充质感。静态轮廓、起势、停顿、收束都要能支持同一种情绪；测试只能验证运动和几何约束，不能证明人的情绪识别准确率。

本项目默认使用 [Rive 开源运行时](https://github.com/rive-app/rive-runtime) 的完整状态机与向量绘制，Web 和 Plasma 共享同一份 `.riv`。素材由共享姿态和动作台本生成；Sentient Eye Engine 的 MIT 五点样条仍作为几何来源。选型、授权与 Qt 适配见 [ADR-005](decisions/005-rive-performance-runtime.md) 和 [Rive 集成说明](../vendor/rive/README.md)。

注意组织参考 [Disney Research — Realistic and Interactive Robot Gaze](https://la.disneyresearch.com/publication/realistic-and-interactive-robot-gaze/) 的注意与执行分层、[AnimSchool — Animating the Eye Dart](https://blog.animschool.edu/2022/08/31/animating-the-eye-dart/) 的眼睑拖随。以下幅度与材质属于 Eyes 的抽象角色设计，并非人眼光学模拟。

## 共享五点眼睑

- 上、下眼睑各五个控制点，等间距位于横向 `u=-1,-0.5,0,0.5,1`。产品使用 Eyes 的端点切线约束 C2 样条，连接处的位置、切线与曲率连续；原始 Catmull–Rom 内核只保留上游一致性校验。弯曲与斜率决定端点切线，避免复制端点造成笑眼两侧反向弯折。
- `la/ra` 控制共享弯带；`lu/ld/ru/rd` 控制端点斜率；`luc/llc/ruc/rlc` 控制上下眼睑中央张力；`lu1/lu3/ld1/ld3` 及右眼对应参数控制两处中段。全部进入同一套连续弹簧。
- `getEyeGeometry` 将眼睑编译为四段三次系数。素材生成器将它们无损转换为 Rive 三次顶点及切线；上下共十个顶点，角点的侧向切线长度为零。原 Canvas / GLSL 路径继续用于降级和共享几何参考，产品的向量路径由 Rive 播放。
- 每种情绪包含静止、起势、主动作、跟随与收束五种基姿。三个互补动作都由共享模型时钟、五次缓动和独立弹簧连续混合，不播放独立的眼睑循环。每个动作基姿以两倍增量制作、以至多半权重混合，支持动作重叠与中途切换。眼睑、视线与反光相位来自同一时钟；重复状态不重播起势，暂停不会积累隐藏相位。
- 提眼、收眼以上眼睑行程为主；缩短眼高时中心略下移，下眼睑更稳定。左右眼使用不同的启动时间和局部张力，不让整双眼睛在同一拍同步胀缩。姿态弹簧接近临界阻尼，困倦切换更慢，惊讶更快。
- 所有状态的上下边界不能相交。开心上下控制点偏移严格相同，保留恒定厚度；注意和微动作也须保持该约束。
- 主体仍是无圆角矩形/弯带，侧边清晰，外轮廓只保留像素级抗锯齿。柔边仅作用于内部光场。
- `getLayout` 同时供 Web 和桌面使用：沉浸纵向拉长 1.28 倍，中心在屏幕高度约 43%，纵向注意位移乘 0.7；大屏不设固定像素上限。

### 每种心情的身段

眼睑基姿烘焙在 Rive 素材里；身段只驱动运行时输入，由 `eyes-core.js` 的 `MOOD_ACTING` 统一定义：整脸远近（`lean`，均匀缩放，正值靠近观察者）、额外俯仰（`nod`，正值低头）、节拍上的回弹冲量和眨眼。远近与俯仰按「起势、动作一、二、三」四个包络加权，包络与眼睑相同，再乘活泼程度。远近经临界阻尼弹簧限制在 ±2% 内，俯仰仍受 ±0.28 弧度限制。节拍事件按表演时间触发：暂停或关闭自然动作时不推进，恢复后按原节拍继续，不会补发错过的事件。

| 状态 | 身段 | 节拍事件 | 眨眼习惯（间隔起点 / 双眨概率 / 时长倍数） |
| --- | --- | --- | --- |
| 待命 | 吸气时脸微微靠近、轻抬头（约 0.2%、0.3°） | 无 | 4.5 秒 / 16% / 1 |
| 开心 | 起势与笑意加深时靠近、抬下巴；先向一侧歪头，再向另一侧轻摆 | 笑意加深时咯咯两跳，之后再轻跳一下 | 5.2 秒 / 22% / 1 |
| 好奇 | 起势与首次探看时探身靠近（默认约 1.3%），检查另一侧时低头细看 | 首次探看时拉高一下 | 5.4 秒 / 10% / 1 |
| 思考 | 先后仰并歪头，视线随眼睑慢慢游移；想通时前倾抬头 | 想通时拉高一下，70% 概率眨眼 | 5.6 秒 / 12% / 1 |
| 专注 | 起势时前倾俯身，收束时再轻轻靠近 | 收束时轻压一下 | 6.5 秒 / 6% / 0.92 |
| 惊讶 | 起势时后缩、抬头；二次睁大时再后缩 | 起势结束（约 0.88 秒）必定双眨眼；二次睁大时拉高 | 4.2 秒 / 30% / 0.9 |
| 困倦 | 起势低头；每次眼皮下垂都打盹点头（默认合计约 2.6°），醒来抬头 | 醒来时明显拉高一下，80% 概率双眨眼 | 3.5 秒 / 16% / 1.65 |
| 困惑 | 起势后撤、略低头，发问时凑近，回看时再后撤 | 发问时轻压，回看时拉高 | 4.6 秒 / 26% / 1 |

工作状态以道具动作为主，只保留所属心情六成的起势身段和同样的眨眼习惯；`complete` 完整沿用开心，在自己的节拍上轻跳。思考的前两拍视线随眼睑缓慢移动，想通那一拍仍是快速扫视；其他心情保持「视线先于眼睑」的扫视。

默认显示少量紫色辅助元素，眼形仍是主体。专注配内侧压低的切面眉；好奇只配小问号；困惑配不对称切面眉与较大的问号；开心配大小两颗四角星；惊讶配两侧短线；困倦配两个小 Z；思考与待命不加符号。

这些元素由 `eyes-core.js` 定义无字体向量路径及姿态，素材生成器直接将同一几何编译进 `.riv`。它们共用五种基姿和表情混合弹簧，随切换渐显渐隐；眉毛宽度约为眼宽的 108%，由直线切面构成厚眉头、轻折峰和渐细眉尾，左右轮廓镜像，与眼睛使用同一紫色家族；眉毛倾斜取上眼睑方向，延伸出眼宽的部分也纳入间隙计算，保留清晰的眉眼净空。Rive 中辅助层必须位于眼形上方，Canvas 按同一顺序最后绘制。星星轻随笑眼抬升。它们在眨眼节点之外，不随闭眼压扁。没有额外的符号动画时钟、随机飘动或持续闪烁；减少动态效果保留静态提示，暂停冻结当前姿态。`accents` 默认为开启，显式 `createSimulation({accents:false})` 可关闭整层，Rive 与降级渲染同时响应。

主调试台、缩略图和 `gallery.html` 均加载真实 Rive 素材。对照页默认播放动作，支持重播表情、暂停、隐藏名称和点击眨眼；重播先平滑回到待命，再进入各自状态。暂停后停止重复绘制，后台页面停止更新。浏览器加载失败时回退共享样条，并记录错误，不能把降级截图作为 Rive 验证结果。

## 曲面光场

- 主面光是低对比淡紫漫射密度场，待命宽约 68%、高约 56%、强度约 16%，常态强度约 8–18%，总强度上限 24%。不用亮白色、小亮点或另一只缩小眼睛的路径。
- Rive 的主面光是独立宽阔径向渐变，中心取真实上下样条之间的曲面点。眼睑使用归一化局部坐标，父节点控制宽高，使光场随眼面和眨眼压缩；同一条真实眼形做裁切。主光不采用另一条眼形路径。
- 主光峰值透明度约 16%，待命位置固定；注意使用独立的较慢弹簧输入，继承整眼方向，不独立反向旋转。原 Canvas / GLSL 参考路径保留逐横向位置的精确曲面密度投影；Rive 使用曲面中心投影与眼面裁切，两条材质实现不宣称像素完全一致。
- 两块副反光使用渐弱矩形，沿固定方向移动，交错淡入淡出，峰值透明度约 2.4%，不旋转、不随机抖动。反光周期为 14 秒，`flowphase` 由共享自然时钟驱动，锚点随实际眼睑基姿移动并裁切在真实眼面内。
- 关闭自然动作或减少动态效果时，动作权重平滑归零，反光通过独立的 `flow` 输入淡出，共享相位停止。重新启用时从保留的相位平滑混回动作。

## 动作与注意

- 待命周期 17.3 秒，内含三次约 5.8 秒的连续呼吸；其他情绪仍使用分开的提眼、松眼和局部张力转移，周期分别为开心 13.4 秒、好奇 11.8 秒、思考 14.2 秒、专注 18.7 秒、惊讶 16.1 秒、困倦 15.6 秒、困惑 12.8 秒。呼吸的吸气略短于回落，两只眼共享同一节拍，第三层以极轻的左右重量差打断机械对称。
- 待命呼吸同时改变眼高、眼宽、眼心高度和上下缘弯曲：默认活泼度下眼高总变化约 12%，眼宽约 1.2%，完整活泼度下分别约 18% 和 1.8%。它不是整眼缩放；上眼睑仍承担主要行程。
- 待命每轮在约 3.8 秒与 10.9 秒附近各做一次有停顿的侧看，另有一次很小的回中；光标或显式视线仍拥有更高优先级。四组短句按固定顺序轮换（8 轮约 138 秒后才重复）：右上 / 左下（第一轮，保持原台本）、左上带轻歪头 / 右下、抬眼带歪头 / 左下、右下 / 左上带歪头。各组起拍前后错开不到 1.1 秒，每轮在周期结束前回到静止，接缝处连续。歪头只作用于整脸矩阵，幅度不足 1°。
- 视线比眼睑先到：同一组动作节拍中，视线用不到一半的起势时间（至少 0.12 秒）快速扫到目标并停住，在眼睑开始释放时先启程回中，回程同样压缩到约四成（至少 0.24 秒）。困倦保留缓慢的眼睑节奏。视线弹簧略欠阻尼（约 1.5% 过冲），落点干脆而不晃动；减少动态效果仍使用过阻尼。
- 自然扫视与光标视线一样带动整脸轻微侧倾，方向与视线一致；开心加深笑意时整脸轻歪约 0.7°，随后的提眼反向轻摆约 0.45°；思考收眼时歪头约 0.4°。约 30 秒另有四次稀疏注视微调；待命水平不超过 1.4、垂直不超过 0.53 模型单位，其他情绪保持 0.85 / 0.32，再乘活泼程度；专注缩至 28%，困倦缩至 45%。目标准确位置仍占绝对主导，持续移动会延后微调。
- 开心以弯曲和提眼表达，不改变弯带厚度；好奇和困惑使用不同的左右眼顺序，思考先收后松；困倦下垂约需 1.8–2.2 秒，抬起约 0.7–0.85 秒。专注保持克制，整眼回弹很轻。
- 眨眼约 85ms 闭合、35ms 停留、200ms 睁开，双眨眼第二次延后约 390ms。Rive 的闭眼节点缩到约 1.2% 高度并向下移 31% 眼高，使上眼睑承担主要行程；困倦时序乘 1.65，专注乘 0.92。
- 自动眨眼间隔在各自起点上随机增加 0–2.6 秒，例如待命 4.5–7.1 秒、专注 6.5–9.1 秒、困倦 3.5–6.1 秒；工作状态沿用所属心情的习惯（见上表）。专注较少双眨眼，惊讶和困惑较多。手动眨眼不受自然动作开关限制。
- 较大的注意转移常伴随一次眨眼：一个时间常数 0.3 秒的慢跟随量度目标视线刚刚跳开的距离，超过 15 单位时按约 55% 概率（专注 35%）在移动途中眨眼，距离回落到 5 单位以下才重新判定。缓慢追随光标积累不到这段领先量，不会额外眨眼；距上次眨眼不足 1.6 秒、惊讶起势期间、关闭自然动作或减少动态效果时都不触发。此次眨眼同样推迟下一次自动眨眼，总频率仍在正常范围。
- 切换心情时整张脸有一次带符号的拉伸 / 压扁回弹：惊讶、开心、好奇与待命先拉高，专注、思考、困惑、困倦先轻收；约 0.07 秒到峰、0.36 秒周期、按 e^(-6t) 衰减，默认活泼度下峰值约 0.3%–1.9%，总量限制在 3% 以内。工作状态频繁上报，按基础情绪的六成；完成沿用开心。回弹是受冲量激励的阻尼振子，过程中再次切换只叠加冲量，不会让整脸比例跳变。
- 光标静止 3 秒以上后再次移动，或光标首次出现，双眼轻轻拉高一下表示注意到；持续移动和 2.5 单位以内的抖动不触发。
- 视线先到，眼睑、微倾斜与光场随后收束。注意改变近侧开合、间距和局部节点，幅度受控，保留当前情绪。水平视线约 ±40，垂直约 ±28。
- 重复发送同一状态不重播起势；`complete` 开心约 4.5 秒后自动隐藏，只读命令不改变计时。共享模型控制注视、动作权重和眨眼调度，Rive 的分层混合应用眼睑、辅助元素、注意形变和材质。
- 各心情的节拍回弹沿用同一个阻尼振子，冲量强度 0.35–0.8（切换回弹为 0.35–1.7），最强的是困倦醒来；与切换回弹叠加时总量仍限制在 3% 以内。
- 以上扫视、眨眼、回弹与歪头都只驱动运行时输入（视线位移、整脸矩阵含远近与俯仰、挤压回弹与 `blink`），不改变 Rive 素材中烘焙的眼形基姿。
- 减少动态效果关闭自发动作和回弹，保留手动切换、眨眼和目标跟随。浏览器只追踪页面内指针；桌面保留 KWin 最后一个有效全局坐标，未知坐标不回退到 Wayland 的无焦点原点。

## 验证

上游 Python 样条与原始 JavaScript 内核逐点比较；产品 C2 样条单独检查内部节点的位置、切线和曲率连续，开心弧线不得出现反向肩部曲率。浏览器模块和 QML 合并包必须产生相同系数。模型回归覆盖所有表情互切、眨眼、局部节点动作、开心等厚、曲面光核心完整留在眼面内、暂停恢复及极端屏幕比例。

`tests/rive.test.mjs` 加载真正的 WASM 运行时，覆盖全部 64 种可打断过渡、起势、眨眼、近侧形变、减少动态效果和素材校验。两份 Rive 实例以不同播放进度和速率接收同一模型输入时，眼睑和反光姿态必须相同。辅助元素额外检查真实向量姿态、暂停，以及原生 GPU 中的实际可见像素、开关清除、问号渐隐和眨眼不变形。Qt 在全部 28 种姿态上下缘各取九处位置，验证真实轮廓、透明背景、开心等厚、闭眼和输出尺寸。离屏测试显式使用 RHI 后端，实际桌面仍须检查加载日志、全局光标、输入穿透和完成后自动隐藏。

## 二十种工作状态

工作状态表达“在做什么”，八种情绪表达“心情如何”。两者都使用同一套样条、弹簧、起势与三个互补动作；状态不会叠加独立的随机循环。辅助道具为紫色向量实体，保留双眼的视觉中心。纸张、终端与手册进入双眼下方的操作区域；放大镜靠近被检查的眼睛。正面、侧面厚度、折角和切面明暗构成立体层次，不使用位图贴图或模糊阴影。道具继承脸部注视与倾斜，还按当前视角连续转向并缩短远侧宽度，保持小幅透视，不独立巡游、不随眨眼挤压。纸笔、终端等实际路径在共享核心中定义，并制作进同一 Rive 素材。

| ID | 表演台本 | 辅助元素 |
| --- | --- | --- |
| `listening` | 舒展开眼，右眼先轻提，另一眼接住，温和停住 | 无 |
| `planning` | 侧上方凝视，压住一边思考，再抬另一边确认下一步 | 三层台阶 |

| `searching` | 左侧探看，换右侧抬眼，再收眼检查线索 | 放大镜 |
| `creating` | 先抬眼睁开，右眼带起期待，另一眼跟上，小小得意地收住 | 新纸与加号 |

起势通常约 0.3 秒，保持和释放后回到基姿。动作之间留出安静的停顿；编辑和阅读节奏稍快，等待与遇阻停顿更长。少量道具承担可识别性，眼形和注视承担性格；`accents:false` 时，动作的先后与方向仍可区分。

`complete` / `activity complete` 在桌面与调试台保持约 4.5 秒的开心展示，再淡出；查询状态不重置计时。工作状态可以随时被下一动作平滑打断，同一状态重复上报不重播起势。关闭自然动作或减少动态效果时，停止扫视、起势、道具提落与反光流动，保留静态眼形和道具。光标注意始终优先于自然扫视。

自动接入能确定文件、命令、MCP、skill、子智能体、压缩、中断和结构化失败等可观察动作；连续失败、重试与阻塞只根据工具响应字段和同类动作的顺序判断，不从未暴露的模型思维中推断。无法映射到事件的阶段仍由 harness 显式报告。设计决策与验证要求见 [ADR-009](decisions/009-agent-activity-performances.md)。

道具的操作量 `propA/propB/propC` 来自同一套眼睑动作权重；落笔、输出、连接与翻页均有明确的起止，没有另一个计时器。透视采用共享 `getPropViewX/Y` 的连续正侧面缩放与旋转；Rive 先重置基准再施加左右或上下转向，避免 1D 混合的前帧残留。Canvas 降级与 Rive 产品共用视角函数。静止时，用户移动光标仍可改变视角；关闭自然动作只冻结自主操作。

抗锯齿回归以相邻实心眼面为基准，将采样像素归一化为覆盖率，检查 10%–90% 的真实中间覆盖；不能用固定绿色通道阈值，把深紫眼睑的 62.5%–87.5% MSAA 覆盖误当作实心像素。继续限制最多两物理像素的过渡，并独立检查轮廓内外与淡出的透明度合成。
